Guide d'utilisation

Modes d'émission

  • PTT (Push-To-Talk) : Maintenez le bouton pour parler, relâchez pour écouter.
  • Continu : Mode appel. Le micro est toujours ouvert (le bouton sert de Mute).

Casque recommandé

En mode Continu, l'utilisation d'un casque évite le larsen (sifflement) dû au retour du haut-parleur dans le micro.
